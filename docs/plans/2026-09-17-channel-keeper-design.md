# 频道收藏站：设计与实施计划

**Goal:** 在 Windows 本机管理多个 YouTube 频道，定时发现更新并自动下载。

**Architecture:** FastAPI 提供本地 API 和静态中文界面，SQLite 保存频道、视频去重记录、任务和设置。扫描线程与下载线程分离，通过独立 yt-dlp 子进程执行网络工作，避免阻塞界面；单实例、单下载队列避免重复执行。

**Tech Stack:** Python 3.10+、FastAPI、SQLite、原生 HTML/CSS/JavaScript、yt-dlp、FFmpeg、Node.js。

## 方案选择

本地网页界面不需要前端编译，易维护；桌面封装可后续增加托盘；服务器部署需要额外认证与权限设计。本次交付默认本地网页、绑定 127.0.0.1。

## 产品行为

- 批量粘贴频道 URL 或 @handle；独立编辑名称、扫描周期、分辨率、封装格式和订阅开关。
- 默认首次成功扫描仅建立完整现有视频基线。可选择下载最近 N 条。扫描失败不得完成初始化或提交半份基线。
- 默认监控 /videos；可选择 /shorts。直播不在本次范围。
- 每次完整枚举所选栏目，避免低频扫描时仅取最近几条导致漏检。视频 ID 在频道内唯一，任务 ID 持久化。
- MP4、MKV、WebM 视频，MP3、M4A 音频；画质上限 360p–2160p 或最高，绝不自动超出上限。
- 下载串行，展示当前阶段与分段进度；失败有限次退避重试、手动重试、取消、重启恢复。
- 本地目录、HTTP/SOCKS 代理、Netscape cookies 文件、自动重试次数；依赖诊断与错误可见。
- 关闭浏览器不停止服务；关闭服务或关机暂停。提供可选 Windows 登录自启脚本。

## 实施步骤

1. `app/models.py`：输入校验及频道 URL 白名单；`app/store.py`：事务、去重、持久化。测试非法 URL、首次扫描、重复扫描与失败恢复。
2. `app/engine.py`：yt-dlp 命令、扫描调度、下载进度及重试，子进程超时与停止。测试格式选择、失败保留基线、取消与重启。
3. `app/main.py`：API、生命周期、本机访问保护、单实例锁。通过 TestClient 测试频道/设置/队列和请求保护。
4. `app/static/`：中文响应式管理界面，真实空状态、频道编辑对话框、队列筛选、设置及诊断。浏览器检查交互。
5. `start.cmd`、启动入口、登录自启脚本、README：安装、启动、升级与使用说明。
6. 运行完整测试、语法检查、服务烟雾测试；尝试联网提取公开测试视频，明确记录网络限制。

## 验收

模拟频道从旧视频集变为增加新视频，只有新增视频入队；首次最近 N 条符合配置；失败扫描不污染基线；断点重启恢复；没有 FFmpeg/网络故障时可读错误；API 拒绝外站写入；中文路径正常。真实 YouTube 下载受网络、站点验证和视频可用性影响，单独报告验证范围。
